For practice and so I can apply it to future careers. I have created a sorting algorithm visualizer. With 200 objects to sort. You can run it yourself by opening up the project, going to main, and hitting play.

With learning how to do A* pathfinding recently. I figured it was best to learn some more basics, expanding that to sorting algorithms. Like the A* pathfinding, I wanted to visualize it. So, coding the visualizer with BubbleSort was the first thing I did. When it was done I was able to easily add in more classes as the sorting algorithms. 

In the visualization, I decided to include the time to show how long each sorting method took. Comparing them to one another in a leaderboard. I also wanted to show how many steps were being done per frame. You can change it in the code by going to SortingVisualizer.h and changing "stepsPerFrame." I figured it was good information to know as depending on how many steps were done per frame, it would impact the speed. Like BubbleSort took roughly 35 seconds at 10 steps/frame, yet it took roughly 50 seconds at 8 steps/frame.

My biggest challenge with this was figuring out how to code each sorting algorithm. I wanted to visualize the steps per frame so it wasn't done all within one frame. I couldn't use for loops or while loops in the algorithms. I had to keep a way to track the progress and go to the next step. It was definitely a big hurdle, but I was able to overcome it.
